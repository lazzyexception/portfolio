# Blue Home Realty

Responsive static website based on the supplied Blue Home Realty presentation and business cards.

Open `index.html` or serve this folder with a static web server. No build step is needed. The contact form prepares a WhatsApp message; it does not submit or store enquiries on a server.

Brand artwork and portraits are extracted from user-supplied materials.

The architectural hero is original AI-generated imagery for visual presentation; it is not a property listing. The grey skyline is a high-resolution restoration of the supplied card artwork.
